This is a prototype for a **Human-Emulation-Layer** for an x86 CPU. You are supplied the `intel` syntax asm code and need to manually manipulate the stack, CPU registers, and instruction pointer. Some knowledge of intel x86 asm is required to perform your job of being a CPU, but a manual is provided for some common operators.
